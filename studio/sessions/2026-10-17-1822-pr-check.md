- `studio/README.md`:

  - *Main is the truth*: issues and PR comments are already landed, and a session that changes nothing has nothing to land.

## Learned
- Test a claim about the environment before writing it down: "no GitHub API" was one command away from being disproved.
- After a squash merge, the branch is still "ahead" of main by its own commits. So "is there anything to land" has to compare the merged PR's head with HEAD, not count commits.
